# PRD - Graphic & Multi-Chart Visualization Page

## 1. Feature Overview
The Graphic page (`Graphic.jsx`) allows technicians to configure graphical trend views for measurement channels on SUTO display devices.

## 2. Configuration Schema (`cfgGraphic.json`)
- Defines active chart views, trend lines, assigned channel IDs, line colors, and axis bounds.
- Users can create multiple chart tabs, reorder charts, and delete chart tabs.
